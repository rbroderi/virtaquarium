# Virtual aquarium: TypeScript build

A strictly typed TypeScript port of the procedural reef aquarium in `../pc/` and its Node tools in
`../tools/`. The JavaScript original is untouched; this directory is self-contained (its own
`package.json`, `node_modules`, build and tests).

## Run it

```bash
cd ts
npm install
npm start            # build, then serve on http://localhost:8090/ts/web/
```

Pages (all accept the original URL parameters):

| Page | URL |
|---|---|
| Tank | `/ts/web/index.html?seed=7&clock=1&feed=4&drift=0&tank=tanks/example.json&scenery=jelly&capture` |
| Fish lab | `/ts/web/lab.html?sp=clownfish` |
| Roku baker | `/ts/web/bake.html` (normally run headless: `npm run bake -- --species=clownfish`) |
| Roku simulator | `/ts/web/roku.html` |

Other scripts:

| Script | What it does |
|---|---|
| `npm run build` / `npm run watch` | esbuild bundles `src/{main,lab,bake,roku}.ts` into `web/build/` and writes `web/build/source-hash.json` |
| `npm run serve` | static server (`tools/serve.ts`, port 8090) |
| `npm run typecheck` | `tsc --noEmit` over `src/`, `tools/` and `test/` |
| `npm test` | vitest |
| `npm run check -- motion --seed=7` | headless tank checks (`tools/check.ts`: motion, look, critters, startup, perf) |
| `npm run bake` | headless Roku asset bake into `../roku/assets/` |

Assets: the pages read `./models/` and `./ref/` relative to `/ts/web/`. The server layers those over
the JS build's `pc/models/` and `pc/ref/`: files this build writes (its skin cache, reef-light cache,
lab references) go to `ts/web/models/` and `ts/web/ref/` (git-ignored) and win; everything else comes
read-only from `pc/`. Check output goes to `ts/out/`.

## Type discipline

`tsconfig.json` enables `strict`, `noUncheckedIndexedAccess`, `exactOptionalPropertyTypes`,
`noImplicitOverride`, `noImplicitReturns` and `verbatimModuleSyntax`. The code has no `any` and no
`@ts-ignore`. Untyped input (fetched JSON, URL params, GLB headers, the Self-Profiling API) enters as
`unknown` and is narrowed by a parser at the boundary. three.js is typed by `@types/three`.

## Architecture

```
src/
  main.ts              composition root: parse options, gate the tank, build, stock, wire, loop
  app/                 the tank page's application layer
    options.ts         URL switches -> AppOptions
    stage.ts           StageBuilder: renderer, scene, camera, sun, water renderer, photo camera
    lighting.ts        LightingController: light level -> lights, fog, exposure, uniforms
    daylight.ts        DaylightSource strategies: always day / wall clock
    feeder.ts          Feeder: publishes `feed` events on the EventBus
    stocking.ts        stockTank: fish placement strategies, critter factory, jellies, shelters
    viewer.ts          pointer at the glass -> world.viewer
    tankLoop.ts        TankLoop: step / present / frame
    handle.ts          AquariumHandle: the typed interface the checks receive
  config/tankConfig.ts the tank document gate (normalizeTank, loadTank), no three.js dependency
  tank.ts              the gate bound to the real species catalogue
  core/                rng, math, noise, colour, canvas, DOM narrowing, EventBus, organic (warp/mottle)
  lod.ts               fish body levels of detail (meshoptimizer), picked per draw
  species.ts, species/ typed species catalogue, SpeciesRegistry
  anatomy/             fitted anatomy data (generated by tools/fit-anatomy.mjs)
  fishModel.ts, fishModel/  procedural fish meshes, skins, fins, swim shader, skin cache, GLB models
  brain.ts, brain/     Brain (drives, perception, decision) + one Behaviour per mode
  fish.ts, fish/       Fish body physics, spine chain
  world.ts, world/     World: shared tank state, food, station, viewer
  reef.ts, reef/       ReefBuilder and the Reef / TankScene types
  water.ts, water/     medium, waves, caustics, backdrop, snow, bubbles, surface, water renderer
  reefLight.ts, reefLight/  baked reef light, its cache, screen-space AO
  critters.ts, critters/    cuttlefish, octopus, turtle, critter factory
  jelly.ts, jelly/     jellies and the jelly tank
  ui.ts, lab.ts, labRef/, bake.ts, roku.ts, roku/, *Check.ts   pages and checks
tools/                 serve.ts, build.ts, bake.ts, check.ts, headless.ts (run with tsx)
test/                  vitest suites
```

Large JS files are split into folders. Each original module path (`water.ts`, `reef.ts`,
`fishModel.ts`, ...) is kept as a barrel that re-exports the same public names.

## Where the patterns live

| Pattern | Where | Why |
|---|---|---|
| Anti-corruption layer / typed gate | `config/tankConfig.ts` `normalizeTank(unknown) -> Tank`; `roku/manifest.ts`, `reef/scenery.ts` `parseSceneryManifest`, `fishModel` `parseModelConfig`, `labRef/refs.ts` | Untrusted documents become validated types in one place |
| Dependency inversion | `tankConfig` takes a `HabitatCatalogue`; consumer-side ports such as `CritterWorld`, `SwimWorld`, `FanWormWorld`, `ReefLightTarget`, `LabHost`, `UIWorld`; injected fetchers and clocks | Modules depend on what they use, so they can be tested and wired at the root |
| Strategy | `brain/behaviours/*` (one `Behaviour` per mode, from `brain/registry.ts`); `rig.ts` light rigs; `app/daylight.ts`; `app/stocking.ts` fish placements | Replaces long `switch` and `if` chains |
| Registry / Factory | `SpeciesRegistry` (`species.ts`); `createCritter` (`critters/factory.ts`); `BEHAVIOURS` | Builds or looks up by id without type switches |
| Observer | `core/eventBus.ts` with `TankEvents` (`app/feeder.ts`); the feeder, click and F key publish `feed`, and the world subscribes | Producers of feed requests don't know the world |
| Builder | `reef/builder.ts` `ReefBuilder` (named layout steps in the original order); `app/stage.ts` `StageBuilder` | Step-by-step construction of complex scenes |

## Fidelity to the JS build

The port keeps the order of random-number draws, the floating-point maths and the GLSL. The same
seed builds the same tank.

- `test/reefLayout.test.ts` builds the reef headlessly (with a fake canvas) and compares homes,
  caves, shelters, anemones, height samples and vertex counts with `pc/src/reef.js`, for seeds 7
  and 42.
- `test/speciesParity.test.ts` compares the full processed species catalogue with `pc/src/species.js`.
- `test/rng.test.ts` checks `mulberry32` bit for bit against `pc/src/util.js`.

Known, deliberate differences:

- **Separate caches.** The reef-light and skin caches use keys from the TS sources (a build-time
  fingerprint replaces fetching source files), so the first TS run re-bakes and repaints and saves
  into `ts/web/models/`.
- **Counters start at 0.** Brain counters that the JS left `undefined` until first use now start at
  0, and a fan worm's first scare no longer waits a `NaN` frame. Neither change draws random
  numbers.
- **Synced with `main` at cb72400** (organic pass, body LODs, perf check, spine-chain collision,
  glass reflection off by default). Later edits to `pc/` need porting.
- **LOD weights fixed.** `lod.ts` counts a per-component weight such as the body's uv `[2, 6]`; the JS
  tested `[2, 6] > 0` (false), so its body LODs ignore the UVs. Fish LOD meshes differ slightly.
